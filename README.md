# Linux in Cyber Security

## Overview

This repository contains my Self-Learning Activity (SLA) submission for the Operating Systems course.

The project focuses on understanding the importance of Linux in Cyber Security. The article explains Linux fundamentals, its security features, practical applications, advantages, challenges, and its role in ethical hacking, digital forensics, cloud computing, and enterprise security.
